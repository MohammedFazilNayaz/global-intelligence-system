## 1. Executive Summary

Phase **V0.8.5 ("Global Intelligence Expansion")** must satisfy an uncompromising set of **22 Acceptance Gates** before development may proceed to **V0.9 (Interactive 3D/2D Globe)**.

Under this quality framework, arbitrary raw counts (e.g. counting hundreds of ungrounded events or empty database rows) are strictly barred from passing. Every acceptance gate is verifiable through automated test assertions, empirical database SQL queries, or audited precision benchmarks.

## 3. Detailed Verification Procedures

### 3.1 Verification for GATE-01 & GATE-02 (Source Fleet & Regional Presence)
```sql
-- Verify 25 operational sources across all 11 global regions
SELECT 
    s.region,
    COUNT(s.id) AS total_sources,
    COUNT(s.id) FILTER (WHERE s.active = true) AS active_sources,
    COUNT(s.id) FILTER (WHERE s.freshness_status = 'CURRENT') AS current_sources
FROM sources s
GROUP BY s.region
ORDER BY total_sources DESC;
```
*Acceptance Rule:*
- Result must contain exactly 11 distinct regions.
- Every region must have `active_sources >= 1`.
- Total sum of `active_sources` across all rows must be $\ge 25$.

---

### 3.2 Verification for GATE-04 & GATE-05 (Disaggregated Primary Ratios)
```sql
-- Compute textual primary source ratio
SELECT 
    COUNT(*) AS total_text_documents,
    COUNT(*) FILTER (WHERE s.is_primary = true) AS primary_documents,
    ROUND((COUNT(*) FILTER (WHERE s.is_primary = true)::numeric / COUNT(*)::numeric) * 100, 2) AS primary_ratio_pct
FROM documents d
JOIN sources s ON d.source_id = s.id
WHERE s.domain NOT IN ('Market Telemetry', 'Natural Disasters');
```
*Acceptance Rule:*
- `primary_ratio_pct` must be $\ge 30.00\%$.
- Sensor telemetry (CoinGecko, Finnhub, USGS) is excluded from the denominator to prevent artificial inflation.

---

### 3.3 Verification for GATE-11 & GATE-12 (Knowledge Graph Quality)
```sql
-- Inspect knowledge graph edge density, confidence, and provenance
SELECT 
    COUNT(*) AS total_relationships,
    COUNT(DISTINCT relationship_type) AS distinct_types,
    ROUND(AVG(confidence)::numeric, 3) AS average_confidence,
    MIN(LENGTH(evidence)) AS min_evidence_length,
    COUNT(*) FILTER (WHERE source_document_id IS NULL) AS ungrounded_edges
FROM entity_relationships;
```
*Acceptance Rule:*
- `total_relationships` $\ge 100$.
- `distinct_types` $\ge 6$.
- `average_confidence` $\ge 0.800$.
- `min_evidence_length` $\ge 20$ (guaranteeing real sentence quotes, not placeholder tokens).
- `ungrounded_edges` must equal 0.

---

### 3.4 Verification for GATE-13 & GATE-14 (Empirical Market Telemetry)
```sql
-- Verify real observations exist for all 16 canonical assets
SELECT 
    ma.symbol,
    ma.asset_type,
    COUNT(mo.id) AS total_observations,
    MIN(mo.timestamp) AS oldest_tick_utc,
    MAX(mo.timestamp) AS newest_tick_utc,
    COUNT(DISTINCT mo.source) AS distinct_providers
FROM market_assets ma
LEFT JOIN market_observations mo ON ma.id = mo.market_asset_id
GROUP BY ma.symbol, ma.asset_type
ORDER BY total_observations ASC;
```
*Acceptance Rule:*
- Exactly 16 rows returned.
- `total_observations` must be $> 0$ for all 16 symbols.
- `newest_tick_utc` must be within 24 hours of audit execution.
- No synthetic prices or zero-return placebos.

### 3.5 Verification for GATE-15 (Disaster Intelligence Grounding)
```sql
-- Verify real earthquake coordinates
SELECT 
    event_title,
    event_time,
    confidence,
    raw_metadata->>'latitude' AS latitude,
    raw_metadata->>'longitude' AS longitude,
    raw_metadata->>'magnitude' AS magnitude
FROM extracted_events
WHERE event_type = 'disaster'
ORDER BY event_time DESC
LIMIT 5;
```
*Acceptance Rule:*
- Non-empty result set.
- `latitude` and `longitude` are genuine decimal degrees matching USGS source coordinates. Zero fabricated coordinates.

---

### 3.6 Verification for GATE-18 & GATE-19 (Scheduler Stability & Zero Synthetic Data)
```sql
-- Verify scheduler reliability and zero synthetic records
SELECT 
    (SELECT COUNT(*) FROM ingestion_runs WHERE status = 'FAILED' AND error_message ILIKE '%timed out%') AS scheduler_timeouts,
    (SELECT COUNT(*) FROM market_observations WHERE metadata->>'synthetic' = 'true' OR source = 'DeterministicFeed') AS synthetic_market_rows,
    (SELECT COUNT(*) FROM extracted_events WHERE raw_metadata->>'synthetic' = 'true') AS synthetic_event_rows;
```
*Acceptance Rule:*
- `scheduler_timeouts` = 0.
- `synthetic_market_rows` = 0.
- `synthetic_event_rows` = 0.

## 4. Failure Remediation & Enforcement Protocol

1. **Hard Gate Failure:** If any of the 22 gates fails during the V0.8.5 audit:
   - Development of Phase V0.9 is strictly blocked.
   - The failure must be diagnosed and remedied in the respective service.
   - The audit suite must be re-run in its entirety.
2. **No Waivers for Core Intelligence:** Under no circumstances may a gate be bypassed by lowering thresholds (e.g. lowering precision to 70% or substituting synthetic prices) without an explicit, documented architectural amendment.
