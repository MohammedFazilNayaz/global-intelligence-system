## 2. Forensic Investigation of the Overview 500 Error

### 2.1 Incident Report
- **Endpoint**: `GET /api/v1/dashboard/summary`
- **Response**: `500 Internal Server Error`
- **Traceback**:
  ```text
  pydantic_core._pydantic_core.ValidationError: 1 validation error for EconomicObservationRead
  document_id
    UUID input should be a string, bytes or UUID object [type=uuid_parsing, input_value=None, input_type=NoneType]
  Traceback:
    File "backend/app/services/economic_service.py", line 447, in get_economic_dashboard_summary
      recent_key_releases=[EconomicObservationRead.model_validate(r) for r in key_releases]
  ```

### 2.2 Root Cause Analysis
1. **Production Database Inspection**:
   - A forensic query of `economic_observations` revealed:
     - Total observations: **50**
     - Observations with `document_id IS NULL`: **48**
     - Observations with `document_id IS NOT NULL`: **2**
2. **Telemetry Ingestion Architecture**:
   - In `backend/app/services/macro_ingestion_service.py` (lines 252–265), official macroeconomic telemetry ingested directly from statistical agency APIs (e.g., FRED monthly CPI series `CPIAUCSL`, ECB rate decisions) is recorded as:
     ```python
     obs = EconomicObservation(
         id=uuid.uuid4(),
         indicator_id=indicator.id,
         document_id=None,
         event_id=None,
         observation_period=period_str,
         observation_date=dt,
         reported_value=val,
         ...
     )
     ```
   - These records are quantitative statistical telemetry and do not originate from news text documents.
3. **Database Model Definition**:
   - In `backend/app/models/observation.py` (lines 34–39):
     ```python
     document_id: Mapped[Optional[uuid.UUID]] = mapped_column(
         Uuid,
         ForeignKey("documents.id", ondelete="CASCADE"),
         index=True,
         nullable=True,
     )
     ```
     The SQLAlchemy ORM model explicitly specifies `Optional[uuid.UUID]` and `nullable=True`.
4. **Schema Defect**:
   - In `backend/app/schemas/economic.py` (line 148):
     ```python
     class EconomicObservationRead(BaseModel):
         id: UUID
         indicator_id: UUID
         event_id: Optional[UUID] = None
         document_id: UUID  # <-- DEFECT: Non-nullable, caused Pydantic to reject None
     ```
5. **Frontend Expectations**:
   - In `frontend/src/types/intelligence.ts` (line 204), `EconomicObservation` was already typed as `document_id?: string | null`.
   - In `frontend/src/views/EconomicView.tsx` (line 480), provenance rendering already supported `document_id || 'Direct'`.

### 2.3 Corrective Action
- **Code Modification**: In `backend/app/schemas/economic.py`, updated `document_id`:
  ```python
  class EconomicObservationRead(BaseModel):
      id: UUID
      indicator_id: UUID
      event_id: Optional[UUID] = None
      document_id: Optional[UUID] = None
  ```
- **Regression Verification**: Added `test_direct_macro_telemetry_without_document_in_summary` in `backend/tests/test_api_economic.py`.
- **Live Endpoint Test**:
  - `GET http://127.0.0.1:8000/api/v1/dashboard/summary` → `HTTP 200 OK`
  - `recent_key_releases count: 6`
  - All 6 observations serialized cleanly with `document_id: null`.

## 5. 2D / 3D Projection Parity & State Synchronization Audit

### 5.1 Shared Geographic State
The projection engine (`useGlobeProjection.ts`) manages camera and interaction state uniformly across projection modes:
- **Center Coordinates**: `centerLambda` (longitude in radians) and `centerPhi` (latitude in radians) are shared.
- **Zoom Level**: `zoom` factor ($0.5\times$ to $8.0\times$) persists identically across toggling.
- **Selection State**: Active `selectedEventId` remains highlighted in both projections.
- **Filter State**: Importance, confidence, location state, and freshness filters apply identically to both views.

### 5.2 Mathematical Precision Verification
- **Orthographic (3D)**: Forward equations compute $x = R \cos \phi \sin(\lambda - \lambda_0)$, $y = R (\cos \phi_0 \sin \phi - \sin \phi_0 \cos \phi \cos(\lambda - \lambda_0))$, with clipping test $\cos(c) = \sin \phi_0 \sin \phi + \cos \phi_0 \cos \phi \cos(\lambda - \lambda_0) \le 0$.
- **Equirectangular (2D)**: Cylindrical projection $x = \text{width} \cdot (\lambda + \pi) / (2\pi)$, $y = \text{height} \cdot (\pi/2 - \phi) / \pi$.
- Verified via unit test suite `src/tests/geo_projection.test.ts` (13/13 passed).
