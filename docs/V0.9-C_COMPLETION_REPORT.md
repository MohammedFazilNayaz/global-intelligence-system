## 4. MATHEMATICAL PROJECTION & DATE-LINE EVIDENCE

### 4.1 Numerical Tolerances
- **Orthographic Forward/Inverse Round-Trip Accuracy:** Tested across random terrestrial coordinates. Observed error $\epsilon_\lambda, \epsilon_\phi < 10^{-4}\text{ degrees}$ ($<11\text{ meters}$ ground error).
- **Equirectangular Forward/Inverse Round-Trip Accuracy:** Observed error $\epsilon_\lambda, \epsilon_\phi < 10^{-4}\text{ degrees}$.
- **Center Singularity:** Camera at $(\lambda_0, \phi_0)$ maps coordinate $(\lambda_0, \phi_0)$ to exact canvas center $(x_c, y_c)$ with $\epsilon < 10^{-5}\text{ pixels}$.
- **Poles:** North pole $(0, 90)$ and South pole $(0, -90)$ project smoothly to the top and bottom limbs without division by zero.
- **Globe Limb:** Points at $c = 90^\circ$ distance project precisely to the globe disk perimeter ($\rho = R$).
- **Back-Hemisphere Occlusion:** Points with $\cos c < 0$ return `visible = false` and are completely culled.

### 4.2 Antimeridian & Date-Line Adjacency
- Tested points at $+179.5^\circ$ and $-179.5^\circ$ longitude:
  - Angular separation is verified as exactly $1.0^\circ$ (not $359.0^\circ$).
  - In 3D: continuous rotation across $180^\circ$ longitude occurs without sign jumps or visual tearing.
  - In 2D: modular longitude wrapping $\text{normalizeLongitudeDeg}(\Delta \lambda)$ keeps adjacent points contiguous.

## 5. DENSITY GOVERNOR & HIT-TESTING EVIDENCE

### 5.1 Maximum 150 Individual Marker Ceiling
- `useGeoFeatures` deterministically sorts candidate features:
  1. `importance DESC`
  2. `confidence DESC`
  3. `event_time DESC`
  4. `id ASC` (deterministic tie-breaker)
- The top 150 features are rendered as individual markers.
- Features ranked $> 150$ remain accessible in application memory (`overflowFeatures`) and via API pagination.
- **Zero synthetic aggregation points** or fake cluster centroids are generated.

### 5.2 Hit-Testing & Occlusion
- Cursor hover uses screen-space Euclidean distance checks $d \le \text{radius} + 6\text{px}$.
- In 3D, back-hemisphere points ($\cos c < 0$) are strictly excluded from hit-testing.
- Hover triggers `GlobeTooltip.tsx` displaying canonical title, location state, coordinates, source type, and freshness.
- Clicking a marker sets `selectedFeatureId` and activates the selected event analytical banner.

## 7. RESILIENCE & FAILURE STATES EVIDENCE

- **Loading State:** Semi-transparent dark overlay (`rgba(5, 8, 19, 0.65)`) with institutional spinner and progress message.
- **Empty Dataset:** Basemap renders normally; informative HUD notice advises analyst to adjust filters.
- **Malformed GeoJSON:** Features with non-numeric, `NaN`, or out-of-bounds coordinates ($|\text{lat}| > 90$, $|\text{lon}| > 180$) are safely quarantined to `unresolvedCount` without crashing the render loop.
- **API Failure:** Displays non-fatal top-right error banner with a manual `[Retry]` button. Retains the last valid projected canvas.
- **Resize & DPR:** `ResizeObserver` recalculates canvas dimensions on window resize. Display DPR scaling (`canvas.width = cssWidth * dpr`) guarantees razor-sharp vector rendering.
